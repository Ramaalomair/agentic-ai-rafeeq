# Rafeeq — Agentic AI Capstone (Track 1)

Madar municipal assistant built on the SDAIA Academy capstone starter. Includes local and MCP tools, contextual policy, bounded history, permission-gated writes, audit logging, evaluation tasks, and security checks.

## Setup (macOS / VS Code)

1. Install `uv` if needed: `brew install uv`
2. Run `uv sync`
3. Copy `.env.example` to `.env` and set your own `OPENROUTER_API_KEY`. Never commit `.env`.
4. Run offline checks: `uv run pytest -q tests`
5. Ask a question: `uv run starter.py ask "What is the fee for an illuminated 3 m² sign?"`
6. Try memory: `uv run starter.py chat --session demo`
7. Evaluate: `uv run starter.py eval tasks.jsonl --config A B`

Run all commands from the repository root. Evaluation outputs are saved in `artifacts/capstone/` and must be reviewed before reporting results. Do not claim unrun tests passed.

## Architecture

`starter.py` runs the agent; `agentkit.py` manages the loop and MCP bridge; `madar.py` supplies the municipal domain and local write tools; `servers/madar_mcp.py` exposes read tools over MCP; `AGENTS.md` defines context; `evals.py` grades `tasks.jsonl`.

## Harness

Max steps: 8; cost budget: $0.05 per run; tool result cap: 3000 chars; history cap: 24 messages. Read tools allowed; write tools require approval. Configuration B adds a mandatory fee/date tool-use instruction relative to A.
